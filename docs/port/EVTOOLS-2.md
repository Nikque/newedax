## 1. 足したもの

| 道具 | 変更 | 今までの出力 |
|---|---|---|
| `bookdump`・`bookscan` | 形2の book（`NEDXBOOK`）も読む。`evtool.hpp` の `BookReader`：ファイルを 1MB ずつ自前の入れ物に読み（FILE の入れ物なし）、局面をそこから取り出す。形2は頭の CRC32C、局面の数、尾（記録のバイト数・CRC32C・`BEND`）、尾のあとに何もないことを確かめる。CRC32C は表で計算（new edax の `crc32c_bytes` と同じ約束）。入れ物の大きさは `EVTOOL_BOOK_BUFFER`、FILE の入れ物は `EVTOOL_BOOK_STDIO` で変えられる（比べのため） | 形1の出力は C と同じ（確かめた：2 万・80 万局面）。`bookscan` の 1 行目の局面数を `%llu` で表示（数字は同じ）。途中で切れた形1のファイルは、今までは `bookscan` が統計を出して終わっていたが、止まる |
| `evsearch` | `-window k -decay d`：手数 p の学習のデータに、同じ偶奇の手数 p±2…p±2k のデータを重み d^j で混ぜる（`HANDOFF-eval4.md` 5.1 の 0-6。±1 は偶奇の差で悪くなった記録があるので混ぜない）。試験のデータは手数 p だけ | k=0（既定）は今と同じ出力（確かめた）。`-base` と一緒に使うと、隣の手数の記録にも手数 p の土台の重みを使う |
| `selfplay3` | `-alt p`：探索した局面ごとに確率 p で、最善手以外の合法手を乱数で 1 つ選び、その後の局面を同じ level で探索して、値とともに `sa<手数>.bin` に記録する（同 0-5）。乱数は主の対局と別の系列 | `-alt` なしは C と同じ。`-alt 0.5` でも `sp`・`ss` の 122 ファイルは同じ（確かめた） |
| `trans2rec`（新） | 棋譜（1 行 1 局、`f5d6…`）を手数ごとの記録にする（同 0-2、公開データ v0002 用）。行の手の並びのあとは読まない、`#` の行と空行は飛ばす、パスは自動、`-from`・`-to` で記録する手数、正しくない手は「illegal move」で止まる。終わっていない局は、最後の局面の石の差で記録し、数を表示する | 新しい道具 |
| `build-evtools.ps1` | `trans2rec` を足した。作業ツリー（`runs` の下）では Boost を `third_party` から使う | — |
| `compare_c.py` | 80 万局面の book（B3・B4）。`--repeat` で作業メモリと確保量の最大の幅も表示 | — |
| `test_evtools.py` | 入力を自分で作る（`compare_c.prepare`）。1 件が例外で止まっても残りを流す | — |

v0002 の棋譜の正確な形（行の後ろの欄など）は、データが手元にないので確かめていない（`HANDOFF-eval4.md` 4.2 の 9 の説明だけ）。ダウンロードはしていない。

## 3. 速さ・メモリ（確かめた。交互に 12 回ずつ、1 論理CPU、組ごとの比の中央値）

| 件 | C 比 | 変更の前（`b3`）比 | 最大の作業メモリ（C → C++） | 確保量の最大（C → C++） |

経緯（悪くなった所と直し）：

1. 最初の `BookReader` は記録ごとに `fread` を呼び、変更の前の C++ 比で 1.022・1.034（30 万局面）。
2. 16MB の自前の入れ物にすると 80 万局面で 0.67・0.53 と速くなったが、2 万局面で 1.03〜1.04、`bookscan` の作業メモリ +0.44 MiB・確保量 +0.11 MiB。FILE の入れ物の有無では変わらなかった。16MB で余分に触る理由（C の 16MB の FILE の入れ物との違い）は分かっていない。
3. 入れ物を 1MB にして、すべての件で速く、メモリも少なくなった（上の表）。

- `selfplay3` の C 比 1.008 は探索そのもの（new edax と nikque.17 の C）の差で、この変更の分ではない（変更の前の C++ 比 0.995）。
- 形2の book の読み込みの速さは測っていない（比べる相手の C がない）。CRC32C を表で 1 バイトずつ計算するので、29GB の実 book なら CRC だけで数十秒の見積もり（見立て）。
- `evsearch -window k`：学習のデータが最大 2k+1 倍になり、メモリと時間もほぼ比例して増える（見立て）。`selfplay3 -alt p`：探索が約 1+p 倍（見立て）。
